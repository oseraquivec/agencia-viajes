# Horizonte Tours - Agencia de Viajes

## Objetivo del Sitio
Diseño y desarrollo de un sitio web empresarial informativo para la agencia de viajes ficticia "Horizonte Tours". El proyecto permite a los usuarios conocer la historia de la empresa, explorar un catálogo de 40 paquetes turísticos, consultar preguntas frecuentes y visualizar la información de contacto. 

Este proyecto fue construido estrictamente con HTML5 y CSS3 (Flexbox/Grid), aplicando diseño responsive sin utilizar frameworks de terceros ni JavaScript, como parte de la evaluación de despliegue en Azure App Services.
